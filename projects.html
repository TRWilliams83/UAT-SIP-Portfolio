Project C2: Capillary Canopy

Project C2 is a passive environmental control system built into a 3D-printed terrarium lid. Designed in Fusion 360 and prototyped on a Bambu P1P, the project explores how condensation routing, vent geometry, and integrated moisture control can create tunable microclimates without relying on external equipment.

  • Tools: Fusion 360, Bambu P1P, iterative prototype testing
  • Focus: passive moisture control, fitment, and environmental design
  • Evidence: CAD models, printed revisions, test photos, and SIP documentation
